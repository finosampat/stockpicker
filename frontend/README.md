# StockPicker frontend

Vite + React + TypeScript + Tailwind + shadcn/ui, charts via `lightweight-charts`.

```bash
cp .env.example .env.local   # set VITE_API_URL, or leave empty for mock data
npm install
npm run dev     # http://localhost:5173
npm run lint
npm run build
```

See the root [README](../README.md) and [docs/design.md](../docs/design.md).
